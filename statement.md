# Project Statement

## 1. Problem Statement

The project is a simple command-line Python application that collects basic patient information such as name, age, tumor size, pain, lump, and weight loss. It applies predefined rule-based scoring logic to the entered information and displays an educational cancer risk classification.

The project is intended to demonstrate Python programming fundamentals such as functions, variables, conditional statements, loops, input validation, exception handling, and formatted output. The classification rules are for educational demonstration only and are not medically validated.

## 2. Scope of the Project

The scope of the project is limited to:

- Collecting basic patient information through the command line.
- Validating age, tumor size, and yes/no responses.
- Calculating a score using predefined rule-based conditions.
- Classifying the entered case as Low Risk, Medium Risk, or High Risk according to the program's defined thresholds.
- Displaying the entered details, score, and educational classification.
- Demonstrating core Python programming concepts through a small command-line application.

The project does not provide medical diagnosis, clinical screening, or medically validated risk assessment.

## 3. Target Users

The project is intended for:

- Students learning Python programming fundamentals.
- Instructors or evaluators reviewing a basic Python project.
- Learners interested in understanding input handling, validation, conditional logic, and rule-based classification.

It is not intended for use by patients, doctors, hospitals, or other users for real medical decision-making.

## 4. High-Level Features

- Command-line patient data input.
- Age and tumor-size validation.
- Yes/no input validation for symptoms.
- Rule-based score calculation.
- Educational risk classification.
- Formatted result display.
- Exception handling for invalid numeric input.
- No external Python packages required.

## 5. Educational Disclaimer

This project is developed for educational purposes only. Its rule-based classification is not a medically validated model and must not be used as a diagnosis, medical advice, or a substitute for consultation with a qualified healthcare professional.
